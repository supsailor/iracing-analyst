# Преврати телеметрию в конкретное действие

iRacing Analyst — локальное приложение для разбора кругов iRacing и Le Mans Ultimate. Оно сравнивает лучший круг с типичным темпом, показывает, где появилась разница, и формирует короткий измеримый план на следующий заезд.

Без аккаунта, облака и подписки. Телеметрия остаётся на вашем компьютере.

## Что получает пилот

- **Лучший против медианного** — понятно, что изменилось на самом быстром круге.
- **Конкретные рекомендации** — до трёх измеримых приоритетов вместо общих советов.
- **Проверяемые выводы** — карта, траектория и синхронные графики скорости, газа, тормоза, руля и дельты.
- **Достижимый потенциал** — Sector Optimal складывается из уже выполненных вами сегментов.
- **Понятная сессия** — чистые круги, incidents, out/in laps и незавершённые круги.
- **Автоматическая запись** — запустите portable-приложение перед заездом в iRacing или LMU.
- **Старые сессии** — импортируйте iRacing `.ibt` или официальный LMU `.duckdb`.

## Установка

1. Откройте [последний релиз](https://github.com/supsailor/iracing-analyst/releases/latest) и скачайте `iracing-analyst-v0.2.1-windows-x64.zip`.
2. Полностью распакуйте архив в постоянную папку.
3. Запустите `iracing-analyst.exe`, затем нужный симулятор. Локальный отчёт откроется в браузере автоматически.

Для старой сессии включите запись телеметрии в iRacing сочетанием `Alt+L` и импортируйте полученный `.ibt`.

### Настройка Le Mans Ultimate

Поддержка LMU пока тестируется в ветке `codex/lmu-support` и ещё не входит в публичный релиз v0.2.1.

1. Откройте в LMU `Settings → Gameplay`.
2. Включите `Enable Plugins` и перезапустите игру.
3. Запустите iRacing Analyst до выезда на трассу. Practice, Qualifying, Warmup и Race будут записываться автоматически через встроенный Shared Memory Interface.

Для старой сессии включите в LMU `Automatic Telemetry Recording` и импортируйте `.duckdb` из `Le Mans Ultimate\UserData\Telemetry`. Исходный файл не изменяется.

Официальные материалы LMU: [обновление со Shared Memory Interface](https://guide.lemansultimate.com/hc/en-gb/articles/14556121957775-V1-2-Update-2) и [инструкция по записи телеметрии](https://guide.lemansultimate.com/hc/en-gb/articles/14524956311695-Telemetry-Recording).

### Предупреждение Windows

MVP пока не подписан цифровым сертификатом, поэтому SmartScreen может показать предупреждение о неизвестном издателе. Используйте только архив со страницы Releases этого репозитория и сверяйте SHA-256 checksum.

## Поддержка симуляторов

| Возможность | iRacing | Le Mans Ultimate |
| --- | --- | --- |
| Автоматическая запись | Local SDK | Встроенный Shared Memory |
| Импорт | `.ibt` | `.duckdb` |
| Best / Median / Sector Optimal | Да | Да |
| Карта и траектория | Да | Да, по мировым координатам |
| Газ, тормоз и руль | Да | Да |
| Incidents | `1x/2x/4x` | Только достоверная невалидность круга |
| Названия поворотов | Каталог Spa | Автоматические зоны на этапе тестирования |

## Поддерживаемая платформа

- Windows 10/11 x64;
- road layouts и телеметрия локального пилота;
- отдельные отчёты частей события и несколько стинтов;
- названия поворотов Spa и автоматические зоны неизвестных трасс;
- русский и английский интерфейс.

## Ограничения MVP

Oval, dirt, специальная логика дождя, анализ других пилотов и replay, setup advisor, облачная синхронизация и live coaching пока не входят в продукт. Sector Optimal — сумма лучших валидных смысловых сегментов, а не физически склеенный micro-optimal lap.

## Приватность

Все данные обрабатываются и сохраняются локально. Приложение не использует web API симуляторов, OAuth, LLM, аналитику или облачные сервисы.
