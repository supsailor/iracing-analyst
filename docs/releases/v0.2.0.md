# iRacing Analyst v0.2.0 — First public MVP

iRacing Analyst turns your local iRacing telemetry into a clear answer to two questions: **why was my best lap faster, and what should I try next?**

## Highlights

- Automatic live capture through the local iRacing SDK.
- Import existing `.ibt` telemetry files.
- Separate Practice, Qualify and Race reports, including multiple stints.
- Best vs Median comparison and Sector Optimal potential.
- Interactive track map, racing lines and curated Spa corner names.
- Synchronized speed, throttle, brake, steering and delta charts.
- Ranked corner insights, incident markers and selectable laps.
- Up to three measurable recommendations for the next run.
- English and Russian interface.
- Fully local processing with no account, cloud upload, OAuth or LLM.

## Install

1. Download `iracing-analyst-v0.2.0-windows-x64.zip` below.
2. Verify it using `iracing-analyst-v0.2.0-windows-x64.zip.sha256`.
3. Extract the complete archive and run `iracing-analyst.exe`.
4. Start iRacing and drive, or import an `.ibt` file from the UI.

## Supported

- Windows 10/11 x64.
- Road layouts and the local player's telemetry.
- Curated corner names for Spa; automatically detected zones elsewhere.

## Known MVP limitations

- The executable is not code-signed and may trigger a Microsoft Defender SmartScreen warning.
- Oval, dirt and rain-specific coaching are not implemented.
- Other drivers, replay analysis, setup advice, cloud sync and live coaching are out of scope.
- Sector Optimal combines the best valid semantic segments; it is not a physically stitched lap.
- Recommendations are omitted when there is not enough reliable evidence.

Only download builds from this repository's Releases page and verify the published checksum.
