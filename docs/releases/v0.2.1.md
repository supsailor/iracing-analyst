# iRacing Analyst v0.2.1 — Telemetry recovery fix

This patch fixes corrupted reports that could appear after reconnecting, towing or resetting during one iRacing session.

## Fixed

- Capture fragments with overlapping session times are separated before lap analysis.
- Reused iRacing lap numbers are represented as separate physical laps.
- Zero-length segments can no longer produce an impossible Sector Optimal or a potential gap of tens of seconds.
- Invalid incident-counter resets no longer appear as thousands of incident points.
- Track maps are generated only from continuous valid laps.
- Existing reports are automatically reanalyzed from their local NPZ telemetry; source files are not modified.

When recovery is possible, the report identifies recovered data and excludes damaged fragments. If a result cannot be verified, Sector Optimal, Potential and recommendations are hidden instead of showing a misleading number.

## Install

1. Download `iracing-analyst-v0.2.1-windows-x64.zip` below.
2. Verify it with `iracing-analyst-v0.2.1-windows-x64.zip.sha256`.
3. Extract the complete archive and run `iracing-analyst.exe`.

Existing v0.2.0 data is retained and reanalyzed automatically on first launch.

## Notes

- Windows 10/11 x64 and road layouts remain the supported target.
- Analysis remains local and limited to the local player's telemetry.
- The executable is not code-signed and may trigger a Microsoft Defender SmartScreen warning.
